在 TradingView 里怎么设置

  1. 需要 TradingView 付费套餐，并且账号开启了两步验证（TradingView 的 webhook 功能要求）。
  2. 建告警时打开“通知”页，勾选 Webhook URL，粘贴上面的地址。
  3. “消息”一栏推荐写成下面的 JSON。TradingView 会把 {% raw %}{{ticker}}{% endraw %} 这类占位符换成实际值。
{% raw %}{"ticker": "{{ticker}}", "exchange": "{{exchange}}", "price": {{close}}, "interval": "{{interval}}", "action": "buy", "message": "突破前高"}{% endraw %}

action 写 buy、long、up 显示 🟢，写 sell、short、down 显示 🔴，不写显示 🔔。策略告警可以写 {% raw %}"{{strategy.order.action}}"{% endraw %}。 消息不是 JSON 也可以，会按原文转发。
